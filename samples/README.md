# Demo models

These eight synthetic models ship with Iris. The six Northbank
IFCs and the two PC-03 STEP files were generated by the team's own scripts; the generator is not included. They
contain no customer data. A normal clone includes them; no private access, separate download or Git LFS is required.

## Included files

| Files | Purpose |
|---|---|
| `Northbank-Architecture.ifc`, `Northbank-MEP.ifc`, `Northbank-Site.ifc`, `Northbank-Structure.ifc` | The four files opened by the Northbank demo card |
| `Northbank-Grids.ifc` | Shared grid/level reference |
| `Northbank-MEP-Rev04.ifc` | Designer's fixed revision, for comparison with Iris's fixes |
| `PC-03-Palletising-Cell-RevA.step` | The machine demo, with planted coordination problems |
| `PC-03-Palletising-Cell-RevB.step` | Designer's fixed machine revision |

Together the files are about 15 MB. They are generated outputs, copied byte for byte; no generator code, Revit
files or other application code is included. Original metadata, IFC GlobalIds, geometry and federation coordinates
are preserved. `.gitattributes` disables newline conversion for these files. Regenerate them with the generator
rather than editing the IFC/STEP text by hand.

## Sample drawings

`drawings/` holds two generated MEP plan sheets of Northbank Level 02 for the 2D drawing reader
([docs/drawings.md](../docs/drawings.md)): `Northbank-M-201.pdf`, drawn from the models with their own tags and sizes,
and `Northbank-M-201-mismatch.pdf`, the same sheet with four planted differences (a changed size, a missing run, an
extra run, a pipe drawn as a duct). Each has a `.truth.json` answer key (every item with its tag, kind, size, box in
page pixels at 150 dpi and GlobalId, plus the planted mismatches). They are synthetic, drawn by
`evals/make_drawings.py` from the IFCs above, which it only reads. Regenerate them, from the repo root, with
`uv run --directory server python ../evals/make_drawings.py`; `server/tests/test_make_drawings.py` fails when they are
stale.

Each sheet also has a saved reading, `<stem>.reading.json`: the drawing reader's Gemini reply for each page, made once
by `evals/save_drawing_readings.py` (hard cap `--max-usd`, default $0.30) with the PDF's sha256, the prompt's hash
and how the call was made (`settings`); `--check` replays them against the models with no model call.
The server replays it instead of calling the model when that exact PDF is read with that prompt, says it is a saved
reading, and charges nothing ([docs/drawings.md](../docs/drawings.md), "Saved readings"). Run the script again,
from the repo root with `uv run --directory server python ../evals/save_drawing_readings.py`, after regenerating the
PDFs or changing the reader's prompt; until then those sheets are read live.

## Open the demos

Follow [the local setup](../README.md#run-locally), then use the landing page's demo cards. The server lists every
`*.ifc`, `*.step` and `*.stp` at the top of this folder. The fixed revisions are available from **Models** and are
not opened alongside the originals by default.

IFC opens without an API key. STEP converts to IFC when opened; AI part classification needs a configured model
key. Without it the geometry still converts, with generic IFC classes, so the classified machine demo's results
can differ. For a first check without credentials, use the IFC fixture described in the README.

## Optional local files and evaluation data

Other files in `samples/` remain gitignored: use this folder for local models, fixture outputs, reports and
conversion caches. Do not commit customer data. The deploy copies supported data files from this folder to the
public app, so review its contents before deploying.

- Generate the small fixture, from the repo root:
  `uv run --directory server --locked python -m iris.fixtures ../samples/fixture-clash.ifc`.
- Optional Navisworks reports go in `reports/<name>/`, with XML at the top and the referenced images at their
  relative paths. The Northbank three-view export is not included; the built-in detection demo needs no such report.
- `step-cache/` can hold ready, classified STEP conversions. To prepare it, create the directory, configure a
  model key, and open each STEP once. IFC and manifest files are saved by the STEP's hash. The cache is not bundled.
- Some [evals](../evals/README.md) require generator-side answer keys, extra IFCs or Navisworks exports from the private
  generator repository. `DEMO_MODELS` selects that checkout. Those evals are separate from public local setup and unit tests.

The model files needed for both public demo cards are included. A separate public model download is not required.
